# FloatList 用户指南

## 任务与子任务

底部输入框可新增任务或批量粘贴多行。任务菜单可标记正在做、受阻、完成，也可添加一层子任务。父任务只有在全部子任务完成后才能完成；父、子任务各自拥有独立的日期和提醒，不自动继承。

FloatList 只允许一个根任务处于“正在做”，用于飞书签名。每个父任务内部也只允许一个子任务“正在做”，它只写入飞书“子状态”。

## 日期、优先级与提醒

在任务菜单选择“日期与提醒”：

- 优先级：无、低、中、高。
- 仅日期任务：当天结束后才逾期，可选当天 09:00 或提前一天 09:00。
- 有截止时刻：按分钟判断，可选到期时、提前 10 分钟、1 小时或 1 天。
- 自定义提醒可不依附截止日期；有截止时间时，提醒不得晚于截止。

首次保存提醒会请求 macOS 通知权限。拒绝不会丢失时间，可稍后在设置中重新检查。

## 筛选与历史

按 `⌘F` 打开组合筛选，可同时使用关键词、状态、日期和优先级。命中子任务时会保留父任务上下文；任何筛选生效时暂停拖拽，避免对子集排序。

完成的根任务在当天仍显示，隔天从“当前”隐藏，但保留在本地与飞书，可从“已完成”或“全部历史”找到。

## 本地数据

设置页可导入/导出 JSON。任务和设置会防抖保存，真正退出前强制 flush。同步 Client token 不包含在导出文件中，只存 macOS 钥匙串。
