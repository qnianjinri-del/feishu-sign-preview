# FloatList 手工验收清单

## 构建与首次启动

- [ ] 执行 `pnpm install && pnpm tauri dev` 后 1 秒左右可操作
- [ ] 首次启动显示 320×420 左右的窗口和三条演示任务
- [ ] 窗口外围真正透明，无白色矩形底色、系统标题栏或 Dock 图标
- [ ] 面板右上方出现菜单栏图标

## 窗口

- [ ] 顶部空白区域可拖动，按钮、输入框、任务和拖动把手不会移动窗口
- [ ] 从窗口边缘可缩放，范围限制在 260×160 至 520×760
- [ ] 切换其他应用后窗口仍置顶；关闭“始终置顶”后行为改变
- [ ] 点击窗口关闭按钮/关闭事件仅隐藏，应用仍在菜单栏
- [ ] 移动和缩放窗口后退出重启，位置与尺寸恢复
- [ ] 在外接显示器放置窗口、断开显示器并重启，窗口回到主屏右上安全区域

## 任务

- [ ] 点击“添加任务”，空内容 Enter 不创建，非空 Enter 连续创建
- [ ] 粘贴包含空行的多行文本，每个非空行成为一条任务
- [ ] 双击任务、悬停编辑按钮、聚焦后 Enter/F2 均可编辑
- [ ] 编辑时 Enter 保存、Escape 取消，清空后保存会删除
- [ ] 点击圆圈完成/取消完成，删除线与淡化生效且顺序不跳动
- [ ] 任务右键或点击“更多任务操作”可标记为待办、正在做或已完成
- [ ] 标记为正在做后，任务出现绿色背景、左侧绿色指示条和“正在做”徽标
- [ ] 顶部只显示根事项；切换第二个根事项为正在做时，第一个根事项自动恢复为待办
- [ ] 完成正在做任务后，顶部恢复“当前空闲”；取消完成后任务回到待办
- [ ] 父事项菜单可添加一层子事项，子事项缩进显示且不能继续添加孙事项
- [ ] 父事项显示“已完成/总数”进度；隐藏已完成时进度仍按全部子事项计算
- [ ] 子事项可标记为受阻并填写原因，父项进度和顶部同时显示受阻数量
- [ ] 子事项标记为正在做时不改变根事项或顶部签名；同父项旧的正在做子事项恢复为待办
- [ ] 存在未完成子事项时不能完成父事项；新增或重新打开子事项会重开已完成父事项
- [ ] 删除父事项会同时删除其子事项，撤销可完整恢复父子结构
- [ ] 聚焦任务行后按 `⇧F10` 可打开菜单，方向键移动焦点，Escape 关闭
- [ ] 拖动把手可用鼠标/触控板排序，拖动中原位置有占位
- [ ] 删除显示约 4 秒 Toast，点击撤销恢复原位置
- [ ] 聚焦任务行后 Delete/Backspace 可删；输入框中不会误删任务
- [ ] `⌘Z` 撤销、`⌘⇧Z` 重做

## 设置与数据

- [ ] 透明度可在 35%–95% 实时调整且文字不一起变透明
- [ ] 显示/隐藏已完成不会删除任务，统计仍正确
- [ ] 清除已完成先显示轻量二次确认
- [ ] 系统/暗色/亮色主题和紧凑模式有效
- [ ] 标题可双击编辑并跨重启保存
- [ ] 导出 JSON 可读取；导入有效 JSON 替换清单；损坏 JSON 显示错误 Toast
- [ ] 强制结束后重启，最近已完成防抖保存的内容仍存在

## 飞书同步

- [ ] 未启用同步时不访问同步网关，所有本地能力正常可用
- [ ] Client token 保存后只进入 macOS 钥匙串，JSON 导出和 `floatlist.json` 均不含令牌
- [ ] 非本机 HTTP 地址、带用户名密码/query/fragment 的地址被拒绝
- [ ] 第一次连接且本地和飞书都有事项时显示选择界面，不自动覆盖任一侧
- [ ] 选择“合并本地事项”后，本地独有事项上传，飞书已有事项保留
- [ ] 新增、编辑、四态切换、排序、添加子事项、受阻原因和归档可双向同步
- [ ] 根事项标记“正在做”后，飞书“任务状态”只保留一条“在干”，签名显示该根事项
- [ ] 父事项的飞书“子状态”显示当前子事项名称；多个子事项时只显示正在做的一个
- [ ] 飞书主表只保留父/根事项行；子事项完整数据写入父行隐藏字段，不生成重复任务行
- [ ] 子事项“在干”只影响父行“子状态”，不出现在可见“任务状态”或签名
- [ ] 根事项完成当天仍显示，第二天从悬浮框自动隐藏，但飞书记录仍保留
- [ ] 飞书手工修改后，前台轮询或“立即同步”能更新 FloatList
- [ ] 服务停止时本地修改仍成功并显示离线/待同步；服务恢复后 outbox 自动清空
- [ ] 两端基于旧版本同时修改时进入冲突选择，不静默丢失本地 outbox
- [ ] ETag 未变化返回 304 时界面保持稳定，不重建任务列表

## 系统集成
